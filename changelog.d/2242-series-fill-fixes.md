### Fixed
- **Series fill ignored the auto-grab kill switch** (#2242): with **Auto-grab** off in Settings, a series fill still fanned out indexer searches and grabbed the whole series. Fill now creates the books and marks them wanted and monitored, and queues no searches, matching the scheduled wanted sweep.
- **Series fill added the wrong book** (#2238): when a Hardcover series files several books at one position (a box set, a novella and the real volume all at position 1), clicking **add** on one of them created whichever Hardcover listed first. An explicit book id now wins over a position match.
- **Series fill created box sets, and an excluded box set blocked the real book** (#2239): catalog entries whose titles name a box set are now skipped by fill, the same way they are pruned from an author catalogue on ingestion. An excluded book only blocks re-adding that same title, so an excluded box set no longer makes the volume it is named after impossible to add.
- **Series from Hardcover metadata were never linked to Hardcover** (#2245): a series created from a provider series reference got the right `hc-series:` id and no link row, so the series showed "(no Hardcover link)", the catalog diff was unavailable and **Fill** silently did nothing. The link is now recorded as the series is created. Existing series stay unlinked until you link them from the series **Search** button.
