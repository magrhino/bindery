### Fixed
- **Auto-grab off now stops every grab, not most of them** (#2256): the kill switch was checked by each caller rather than at the point a download is dispatched, so three paths never consulted it at all. A bulk **Search** action, adding a single book with "search on add", and adding a book from **Recommendations** all fanned out indexer searches and grabbed releases with **Auto-grab** switched off in `Settings -> General`. The check now lives inside the scheduler's search-and-grab entry point, so it holds for every caller, including any added later. #2242 fixed the same class of bug for series fill; this closes the rest. Books are still created and still marked wanted and monitored, exactly as before, so nothing is lost from the Wanted page: only the automatic download stops.
