### Fixed
- **The setup-funnel cohort no longer excludes every Docker install** — the telemetry server's funnel gate matched only a bare `1.30.1`, but the Docker image reports its version v-prefixed (CI builds it from `git describe --tags --match 'v*'`) while the GoReleaser binaries report the bare form, and the telemetry client accepts and sends both. Every v-prefixed ping therefore failed the gate and was skipped, which is indistinguishable from an install that stalled before its first milestone — precisely the ambiguity the version gate was added to remove. The gate now accepts an optional leading `v`, so both spellings land in the same cohort.
