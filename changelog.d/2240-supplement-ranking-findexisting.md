### Fixed
- **Adding a book no longer binds it to a cue sheet or notes file in another book's folder** (#2240) — the "already owned" check that runs when a book is created (`FindExisting`) never got #2188's supplement ranking, so a `.cue.txt` beside an audiobook could be recorded as the file for a book the user does not own, and the same cue sheet could be handed to two different books in one author sync, each with its on-add search silently skipped. The snapshot walk now applies the same two-tier treatment as the library scan: a supplement-class file (`.txt`, `.rtf`, `.pdf`, comic archives) sitting next to audio is the audiobook's material and never answers, and elsewhere a real container outranks a supplement, which still matches when nothing better does — so text-only and PDF-only libraries keep working. Thanks ianepreston for both reproductions.
