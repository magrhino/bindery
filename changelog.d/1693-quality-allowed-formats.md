### Fixed
- **Quality profile "Allowed formats" is now actually enforced** (#1693) — the checkboxes read as a hard allow-list in the UI, but the rule implementing them was never wired into the search pipeline, so nothing stopped a disallowed format (PDF, mobi) being auto-grabbed when it was the only or best-scoring candidate. Format ranking is a preference, not a filter. Automatic grabs now reject formats the author's profile disallows, and interactive search labels them with the reason instead of hiding them, so you can still pick one deliberately. Releases whose format cannot be read from the title, authors with no quality profile, and profiles with no format list are all unaffected.
