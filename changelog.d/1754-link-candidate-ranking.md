### Fixed

- **"Link metadata" now ranks candidates and links out to them.** Author link candidates were returned in raw provider order with no ranking, so OpenLibrary's per-anthology composite records ("Dan Abnett, David Annandale, John French, ...", one work each) led the list while the real record holding the author's whole catalogue sat further down. Candidates are now ranked by name relevance, then catalogue size, reusing the same helper the normal author search already used. Records are still never merged, so picking a specific provider's record still works. Each candidate also gained a "View on OpenLibrary" link so it can be checked before linking, omitted for providers whose IDs have no stable public page. ([#1754](https://github.com/vavallee/bindery/issues/1754), reported by nzvengeance)
