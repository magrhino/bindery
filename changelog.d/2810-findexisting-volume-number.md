### Fixed
- **Adding the next volume of a series no longer attaches the first volume's file** (#2810): when you add a book, Bindery checks whether the library already has it and, if so, attaches the file and skips the search. That check matched titles by shared words alone, so "Defiance of the Fall 17" matched volume 1's file. In a layout like `Defiance of the Fall 01/Defiance of the Fall_B094JZMCJX_….m4b`, where the number is only in the folder name, the new volume was marked owned, never searched, and nothing new reached Audiobookshelf. The check now compares volume numbers, whether they appear in the title or only in the book folder, the way the series comparison has since #2538. The same rule applies when a finished download is matched to a book.
