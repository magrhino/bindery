### Fixed
- **Editing an unmonitored book no longer triggers an immediate download.** The Update endpoint fires a search whenever a book transitions into `wanted` — a status edit, a "Delete file", or a media-type change that exposes a missing format (#1148). That hook was gated only on the global `autoGrab.enabled` kill-switch, so widening a book to dual-format grabbed the missing format even when the book was explicitly unmonitored, which is the one per-book control for "track this, don't fetch it". The status still flips; only the search is suppressed. The 12-hour wanted scan already honoured `monitored`.
