### Fixed
- **The book detail page now lists every file on the book, each labelled by its own format.** The File section was rendered through `media_type`, which records what Bindery was told to acquire, not what is on disk. A book declaring one format while `book_files` held both showed the wrong badge next to the wrong path, gave the second file no surface at all, and served the wrong format from Download.
- **Delete file can no longer remove a format you were not shown.** A book that was not marked dual-format sent no `?format=`, and a format-less `DELETE /book/{id}/file` enumerates *every* file on the book — so a delete that displayed one path removed both formats. Download and Delete are now always format-scoped, the confirmation dialog lists every path the request will remove, and the wide delete is a separate, explicitly labelled **Delete all files** action.
- **Added a per-file "Forget this file" action** that drops a stale path from Bindery's records without touching disk (the `?path=` deregister mode from #1692, which previously had no UI). Disabled for legacy rows that predate the `book_files` migration, since the server cannot resolve them.
- **Fix match now moves the file you picked** instead of whichever file the format toggle happened to be on.
- **The media badge renders dual-format books correctly.** It was a binary ebook/audiobook check, so `both` displayed as "📖 Ebook".
